# راهنمای فارسی — قالب Nova

## شروع در ۳ دقیقه

1. **نمایش → پوسته‌ها → افزودن → بارگذاری** و نصب `nova-multipurpose.zip`.
2. منوی **«قالب Nova» → «راه‌اندازی»**:
   - نوع سایت را انتخاب کنید (می‌توانید چند مورد را هم‌زمان بزنید):
     - فروشگاه / کسب‌وکار اینترنتی
     - وبلاگ / مجله
     - نمونه‌کار (Portfolio)
     - شرکتی / آژانس
     - خبری / تخصصی
     - لندینگ / تک‌صفحه‌ای
   - رنگ اصلی و مکمل را بگذارید → **فعال‌سازی حالت‌ها**.
   > از این لحظه فقط کدِ همان بخش‌ها روی سایت اجرا می‌شود.
3. **نمایش → منوها**: منوی «منوی اصلی» را بسازید. برای هر آیتم:
   - **آیکون منو** (انتخاب از لیست)
   - **برچسب** (مثلاً «جدید») و رنگ آن
   - **فعال‌سازی مگامنو** → بعد از ذخیره، در **نمایش → ابزارک‌ها** یک ناحیه با نام «مگامنو — عنوان آیتم» ساخته می‌شود؛ هر ابزارکی داخلش بگذارید، داخل مگامنو نمایش داده می‌شود.
4. **قالب Nova → هدرساز**: با تیک زدن، جای هر جزء را مشخص کنید (نوار بالایی / چپ / وسط / راست). هدر چسبان و شفاف هم از همین‌جاست.
5. **قالب Nova → فوترساز**: ستون اضافه کنید؛ نوع هر ستون (لوگو، منو، ابزارک، سوشال، HTML، فرم) و عرض ۱ تا ۱۲.
6. **قالب Nova → داشبورد و طراحی**: رنگ‌ها، گرادیانت (و اینکه کدام اجزا گرادیانت بگیرند)، فونت، اندازه فونت، عرض محتوا، شعاع گوشه‌ها، شبکه‌های اجتماعی، **CSS سفارشی**.
7. **قالب Nova → مدیریت ماژول‌ها**: هر ماژول (نمونه‌کار، استوری، تبلیغات، اسلایدر، پلیر، Ajax، PWA) را روشن/خاموش کنید. اگر حالت «فروشگاه» را انتخاب کرده‌اید ولی نمونه‌کار هم می‌خواهید، فقط ماژول نمونه‌کار را روشن کنید.

## فروشگاه

**قالب Nova → فروشگاه**:

- **چیدمان کالاها**: «کارت‌های هم‌اندازه» (پیش‌فرض، دقیقاً همان چیزی که در وودمارت نبود) یا «Masonry».
- **اجزای کارت محصول**: برچسب تخفیف، امتیاز، قیمت، آیکون سبد، علاقه‌مندی، مقایسه، نمایش سریع، موجودی، برند — هر کدام را خاموش کنید تا در کارت نمایش داده نشود (و کدش هم لود نشود).
- **فیلترها**: دسته، بازه قیمت، ویژگی‌ها، موجودی، برند.
- **تک‌محصول**: جایگاه گالری (چپ/راست/بالا/چسبان)، سبک توضیحات (تب/بخش/آکاردئون)، نمایش ویژگی‌ها، نظرات، محصولات مرتبط، تصاویر ۳۶۰، فرم «مرا مطلع کن».
- برای هر محصول، در ویرایش محصول یک جعبه با نام **«Nova — ویرایشگر حرفه‌ای محصول»** دارید: ادیتور غنی توضیح کوتاه، جدول مشخصات HTML، ویژگی‌های کلید/مقدار، ویدئو، تصاویر ۳۶۰ و تب اختصاصی.

## تبلیغات

- **تبلیغات → افزودن**: تصویر شاخص + لینک، یا کد HTML در ادیتور.
- زون را از جعبه‌ی «زون تبلیغ» انتخاب کنید (زیر هدر، بالای محتوا، ستون کنار، فوتر، بالای فروشگاه، …).
- در هر صفحه با شورتکد `[nova_ads zone="before-content"]` هم می‌شود گذاشت.
- تاریخ شروع/پایان و استثناها (`home,shop,product`) در همان جعبه تنظیم می‌شود؛ آمار نمایش/کلیک امروز هم نمایش داده می‌شود.

## استوری

- **استوری‌ها → افزودن**: تصویر شاخص (مربع)، ویدئو (اختیاری)، لینک «بیشتر».
- نمایش: `[nova_story count="8" title="استوری‌ها"]` یا بلاک/ویجت المنتور.

## پلیر

```
[nova_player src="https://www.aparat.com/v/xxxx"]
[nova_player src="https://youtu.be/xxxx" poster="آدرس کاور"]
[nova_player src="https://site.com/file.mp4" type="local"]
[nova_player src="https://site.com/audio.mp3"]
```
تشخیص منبع خودکار است (یوتیوب، آپارات، ویمئو، دیلی‌موشن، فایل وردپرس، صوت). پنل کنترل اختصاصی: پخش، جای پخش، صدا، سرعت، تمام‌صفحه، کلیدهای میان‌بر.

## ساخت اپ اندروید

1. **مدیریت ماژول‌ها** → «فعال‌سازی PWA» روشن.
2. **پست تایپ و اپ** → نام، نام کوتاه، رنگ و آیکون ۵۱۲×۵۱۲.
3. دکمه **«دانلود بسته اپلیکیشن»** → فایل zip با تنظیمات Capacitor و راهنمای ساخت APK.
4. کاربران موبایل هم می‌توانند بدون نصب از استور، سایت را «افزودن به صفحه اصلی» کنند (کاملاً آفلاین‌پذیر با service worker).

## پرسش‌های رایج

**چطور یک پست تایپ جدید بسازم؟** پنل → «پست تایپ و اپ» → کلید انگلیسی (مثلاً `book`)، نام مفرد/جمع، اسلاگ، آیکون، پشتیبانی‌ها و تاکسونومی‌ها → ذخیره → یک‌بار «تنظیمات → پیوندهای یکتا → ذخیره».

**فونت دلخواه چطور اضافه کنم؟** پنل → داشبورد و طراحی → «فونت سفارشی» → «+ افزودن فونت» → نام، وزن، فرمت و آدرس فایل (می‌توانید از کتابخانه رسانه انتخاب کنید) → ذخیره → همان فونت را برای متن یا تیتر انتخاب کنید.

**CSS سفارشی؟** پنل → داشبورد و طراحی → پایین صفحه «CSS سفارشی».

**چرا با اینکه افزونه‌ی سئو دارم، متاتگ‌ها تکراری نیست؟** اگر Yoast یا رنک‌مث فعال باشد، قالب متاتگ‌های خودش را تولید نمی‌کند.

**چطور بدانم چه چیزی لود می‌شود؟** در هر صفحه فقط چند فایل `nova-*.css/js` می‌بینید؛ اگر ماژولی روی صفحه نیست، فایلش هم نیست.

**سرعت خیلی مهم است؟** در «مدیریت ماژول‌ها» موارد بی‌استفاده را خاموش کنید؛ حالت «حذف کدهای اضافه وردپرس» را روشن بگذارید؛ یک افزونه کش نصب کنید.
