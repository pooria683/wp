# قالب وردپرس «Nova Multipurpose»

قالب چندمنظوره، ماژولار و بهینه‌ی وردپرس با معماری «حالت (Mode)» — یعنی سایت فقط کدِ بخش‌هایی را لود می‌کند که واقعاً استفاده می‌شود.

نسخه: **1.0.0** · سازگار با وردپرس **6.2+** · PHP **7.4+** · المنتور ۳ · ووکامرس ۸+

---

## ۱) نصب سریع

1. فایل `nova-multipurpose.zip` را از **نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته** نصب و فعال کنید.
2. بعد از فعال‌سازی، از منوی **«قالب Nova» → «راه‌اندازی»** نوع سایت را انتخاب کنید (چند انتخابی).
3. با انتخاب هر حالت، فقط ماژول‌های همان حالت ثبت و لود می‌شوند؛ بقیه کدها روی سایت اجرا نمی‌شوند.
4. منوها را در **نمایش ← منوها** بسازید (مگامنو، آیکون و برچسب از همان‌جا تنظیم می‌شود).
5. رنگ‌ها، فونت، هدر و فوتر را از پنل **«قالب Nova»** تنظیم کنید.

> برای اعمال پیوندهای پست‌تایپ‌های جدید یک‌بار **تنظیمات ← پیوندهای یکتا ← ذخیره** را بزنید.

## ۲) معماری بهینه (چرا سایت سنگین نمی‌شود)

| لایه | کار |
|---|---|
| `inc/class-nova-modes.php` | ثبت حالت‌ها و تعیین اینکه چه ماژولی بوت شود (`has()`, `feature()`) |
| `inc/class-nova-assets.php` | لودر شرطی دارایی‌ها + تولید CSS متغیرها به‌صورت inline |
| `inc/class-nova-admin.php` | پنل مدیریت با اسکیمای تعریفی (افزودن تنظیم = یک خط) |

**قواعد لود:**
- فقط دو فایل همیشگی داریم: `base.css` (~۹KB gzip) و `core.js` (~۴KB gzip).
- بقیه فایل‌ها **register** می‌شوند ولی فقط وقتی **enqueue** می‌شوند که صفحه به آن‌ها نیاز داشته باشد:
  - `player.css/js` فقط اگر شورتکد/ویجت/بلاک پلیر در صفحه باشد
  - `shop.js` فقط در صفحات ووکامرس
  - `product.css` فقط در صفحه تک‌محصول
  - `portfolio`, `story`, `ads`, `mega`, `slider`, `rtl` هرکدام جداگانه و شرطی
- تشخیص «نیاز صفحه» هم از نوع صفحه (`is_product`, `is_shop`…) و هم از **محتوای واقعی** (`has_shortcode`, `has_block`, ویجت‌های فعال) انجام می‌شود.
- حالت‌های خاموش هیچ کلاس/کدی ثبت نمی‌کنند (پست‌تایپ، شورتکد، هوک ووکامرس…).
- لود کدهای وردپرس اضافه (emoji، generator، oEmbed اضافه) با گزینه‌ی «حذف کدهای اضافه» انجام می‌شود.
- اسکریپت‌ها `defer` + در فوتر؛ تصاویر `loading=lazy` + `decoding=async`؛ اسلایدر فقط با CSS transform و IntersectionObserver.

## ۶) هوک‌های توسعه‌دهنده

```php
add_filter( 'nova/modes', ... );                 // تغییر حالت‌های فعال
add_filter( 'nova/assets/context', ... );        // اجبار به لود یک ماژول در صفحه‌ای خاص
add_filter( 'nova/css/variables', ... );         // افزودن/تغییر متغیرهای CSS
add_action( 'nova/assets/enqueue', ... );        // enqueue شرطی اختصاصی
do_action( 'woocommerce_…' );                    // همه‌ی هوک‌های ووکامرس دست‌نخورده
```

## ۷) اپلیکیشن موبایل (اندروید)

1. پنل → **ماژول‌ها** → «فعال‌سازی PWA» را روشن کنید.
2. پنل → **پست تایپ و اپ** → نام/نام کوتاه/رنگ/آیکون ۵۱۲×۵۱۲ را تنظیم کنید.
3. روی دکمه‌ی **«دانلود بسته اپلیکیشن»** بزنید: فایل‌های `capacitor.config.json`, `www/index.html`, `README.md` را می‌گیرید.
4. با `npx cap add android` و Android Studio فایل APK/AAB را بسازید (راهنما داخل خود بسته است).
   سایت همچنین «Add to Home Screen» را در اندروید/iOS ارائه می‌دهد (manifest + service worker + صفحه آفلاین).

## ۸) نکات کارایی

- نمونه‌ی واقعی اندازه‌گیری‌شده روی نسخه‌ی تست:
  - صفحه‌ی نوشته: `base + header + footer + blog + player` و `core + player`
  - فروشگاه: `base + header + footer + blog + shop` و `core + shop`
  - صفحه‌ی ساده: `base + header + footer` و `core`
  - `mega/rtl/slider/story/portfolio/ads/product` فقط وقتی همان عنصر روی صفحه هست.
- جمع حجم CSS شرطی صفحه‌ی ساده ≈ ۳۰KB و JS ≈ ۱۶KB (بدون gzip)؛ یعنی قالب عملاً از یک قالب معمولی سبک‌تر است.
- CSS متغیرها یک بلوک inline است، پس با تغییر رنگ‌ها فایل جدید ساخته نمی‌شود.
- هیچ کتابخانه‌ی خارجی (jQuery/Swiper/Owl/FontAwesome) در فرانت لود نمی‌شود؛ آیکون‌ها SVG درون‌خطی‌اند.
- پیشنهاد: کنار قالب یک افزونه‌ی کش (LiteSpeed/WP Rocket) و WebP فعال باشد.

## ۹) چک‌لیست تست انجام‌شده

- فعال‌سازی روی وردپرس ۶.۷ + ووکامرس ۱۱ + ووکامرس فارسی/فارسی‌سازی
- رندر بدون خطای PHP در: صفحه اصلی، فروشگاه، دسته، تک‌محصول، صفحه، ۴۰۴
- ذخیره‌ی همه‌ی صفحه‌های پنل (design / wizard / header / footer / modules / cpt / woo)
- Ajax: فیلتر (قیمت/موجودی/مرتب‌سازی) → تعداد صحیح، quick view، wishlist، compare، «مرا مطلع کن»، جستجوی زنده، load more، رد شدن nonce نامعتبر
- PWA: `nova-manifest.json` با mime صحیح، `nova-sw.js` با `Service-Worker-Allowed`، صفحه آفلاین
- RTL کامل، منوی موبایل، اسلایدر، استوری، پلیر (facade یوتیوب/آپارات)، تب‌های محصول، ۳۶۰
